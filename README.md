# ULS Turizm Operasyon Backup

Bu repo, `ULS-Turizm-Operasyon-ANA` kaynaginin temizlenmis GitHub yedegi icin kullanilir.

Icerik:
- kaynak kod arsivi
- yedek manifesti

Disarida birakilanlar:
- veritabani dosyalari
- cookie/log/gecici dosyalar
- gizli ayarlar ve secret dosyalari
- buyuk yerel backup ve upload arsivleri

## Social Publisher

`social-publisher/`, bes turizm sitesi icin Ingilizce icerik ve Canva marka
gorseli ureterek desteklenen sosyal aglarda gunluk paylasim yapan acik kaynak
Cloud Run servisidir. Kurulum ve platform ayrintilari icin
[`social-publisher/README.md`](social-publisher/README.md) dosyasina bakin.
